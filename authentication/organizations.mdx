## Multi-Organization Support

One Granite account can belong to multiple organizations. This is useful when:

- You work with multiple clients
- You have separate teams/projects
- You want production and development orgs

## Creating an Organization

<Steps>
  <Step title="Sign In">
    Log into Granite with your account
  </Step>

  <Step title="Click Create Organization">
    From the org switcher or after login if you have no orgs
  </Step>

  <Step title="Enter Details">
    | Field | Description | Example |
    |-------|-------------|---------|
    | **Name** | Display name | "Acme Corp" |
    | **Slug** | URL identifier | `acme-corp` |
  </Step>

  <Step title="Create">
    Click **Create Organization**

    You're now an Admin of the new org.
  </Step>
</Steps>

## Organization Slug

The slug is used in API URLs:

```
https://api.getgranite.ai/api/{slug}/your-endpoint
```

Rules:
- Lowercase letters and numbers only
- Hyphens allowed (no spaces)
- Must be unique across all Granite
- Cannot be changed after creation

## Switching Organizations

<Steps>
  <Step title="Click Org Name">
    In the top-left corner, click your organization name
  </Step>

  <Step title="Select Organization">
    Choose from the dropdown list
  </Step>

  <Step title="Switched">
    The dashboard now shows data from the selected org
  </Step>
</Steps>

<Tip>
  You can also switch orgs from `/select-organization` in the URL.
</Tip>

## Organization Isolation

Each organization is completely separate:

| Data | Isolated? |
|------|-----------|
| Processes | Yes |
| Execution logs | Yes |
| API keys | Yes |
| Members | Yes |
| Drivers | Yes |
| Analytics | Yes |

You can't access data across organizations, even as Admin.

## Member Roles by Organization

Your role can differ per organization:

| Organization | Your Role |
|--------------|-----------|
| Acme Corp | Admin |
| Beta Inc | Member |
| Gamma LLC | Viewer |

## Joining an Organization

When someone invites you:

1. You receive an email invitation
2. Sign in with the invited email
3. The org appears in your switcher
4. Accept to join

<Info>
  Invitations are email-specific. Use the same email you were invited with.
</Info>

## Leaving an Organization

To leave an org:

1. Open the organization
2. Go to Members
3. Find yourself
4. Click **Leave Organization**

<Warning>
  If you're the only Admin, you must either:
  - Promote another member to Admin first
  - Delete the organization entirely
</Warning>

## Deleting an Organization

Only Admins can delete an organization:

1. Go to Settings
2. Scroll to Danger Zone
3. Click **Delete Organization**
4. Confirm by typing the org name

<Warning>
  This permanently deletes all data: processes, logs, members, everything.
</Warning>

## Best Practices

<AccordionGroup>
  <Accordion title="Separate production and development">
    Create different orgs for prod and dev environments. Prevents accidental changes to production.
  </Accordion>

  <Accordion title="Use descriptive slugs">
    Choose slugs that identify the org clearly: `acme-prod`, `acme-dev`, `client-xyz`
  </Accordion>

  <Accordion title="Have multiple Admins">
    Don't be the only Admin. If you leave, someone needs to manage the org.
  </Accordion>

  <Accordion title="Review membership quarterly">
    Remove members who no longer need access.
  </Accordion>
</AccordionGroup>
